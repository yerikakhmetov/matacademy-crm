# МатАкадемия CRM

CRM для офлайн-школы математики: ученики, группы, расписание, учителя, лиды/продажи и оплаты.
Веб-приложение с входом по логину и ролями (админ / менеджер / учитель).

## Стек

- **Next.js 16** (App Router, серверные компоненты и server actions)
- **Prisma 6 + PostgreSQL** — база данных (одна СУБД локально и в облаке)
- **Auth.js (NextAuth v5)** — вход по email/паролю + роли
- **TypeScript + Tailwind 4**, собственная дизайн-система (шрифты Onest + Manrope)
- **Деплой:** Vercel + Neon (см. [DEPLOY.md](DEPLOY.md))

## Модули

| Раздел | Что делает |
|---|---|
| **Дашборд** | KPI (ученики, доход за месяц, лиды, задолженность), занятия сегодня, воронка, последние оплаты, «требуют внимания»; у учителя — свой кабинет (его группы и занятия) |
| **Отчёты** | доход по месяцам, способы оплаты, новые лиды, конверсия по источникам; экспорт учеников и оплат в Excel |
| **Напоминания** | должники, ожидающие счета, истекающие абонементы; готовые тексты сообщений + кнопка WhatsApp (wa.me) |
| **Ученики** | список с фильтрами, карточка ученика, история оплат, добавление/редактирование/удаление |
| **Группы** | карточки с наполняемостью, преподавателем и расписанием |
| **Расписание** | недельная сетка занятий; добавление/удаление занятий; отметка посещаемости по дате с автопересчётом % ученика |
| **Журнал** | сводная матрица «ученики × даты занятий» по группе за месяц, итог по каждому ученику и средняя по группе |
| **Учителя** | загрузка, число групп и учеников |
| **Лиды** | канбан-воронка; карточка лида с активностями (звонки/задачи), конверсия по источникам, перевод лида в ученики одним кликом |
| **Оплаты** | движение средств, статусы (оплачено/ожидает/просрочен), приём оплаты и выставление счетов; кнопка «Отметить оплаченным» |

**Задолженность считается автоматически:** долг ученика = сумма неоплаченных счетов (ожидают + просрочены). Баланс пересчитывается при каждом изменении оплат — вручную не вводится.

**Абонементы:** оформление на карточке ученика с тарифом, сроком (дата окончания = начало + месяцы) и статусом (Активен / Истекает / Истёк). При оформлении автоматически создаётся счёт на оплату. Просроченные счета помечаются автоматически по дате.

## Быстрый старт (локально)

Нужен PostgreSQL. Проще всего — через Docker:

```bash
docker run -d --name matacademy-pg -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=matacademy -p 5434:5432 postgres:16

cp .env.example .env    # строки уже настроены на локальный Docker
# впишите AUTH_SECRET: openssl rand -base64 32

npm install
npm run setup   # применяет миграции и наполняет демо-данными
npm run dev     # http://localhost:3000
```

### Демо-доступы

| Роль | Email | Пароль |
|---|---|---|
| Администратор | admin@matacademy.kz | admin123 |
| Менеджер | manager@matacademy.kz | manager123 |
| Преподаватель | teacher@matacademy.kz | teacher123 |

> Админ и менеджер видят всё и редактируют данные. Преподаватель видит только свои группы,
> расписание и журнал, отмечает посещаемость своих занятий; финансы/лиды/отчёты ему недоступны.
> **Обязательно смените пароли перед реальным использованием** (см. `prisma/seed.ts`).

## Полезные команды

```bash
npm run dev        # режим разработки
npm run build      # прод-сборка
npm run db:seed    # перезалить демо-данные
npm run db:studio  # Prisma Studio — визуальный редактор базы
```

## Структура

```
app/
  (app)/            модули под общей оболочкой (сайдбар + топбар), защищены входом
    dashboard/ students/ groups/ schedule/ teachers/ leads/ payments/
  login/            страница входа
  actions/          server actions (авторизация + CRUD с проверкой ролей)
components/          Sidebar, Topbar, ModalButton, Icon
lib/                prisma-клиент, форматирование, роли
prisma/             schema.prisma + seed.ts (демо-данные)
auth.ts, auth.config.ts, proxy.ts   конфигурация Auth.js и защита маршрутов
```
